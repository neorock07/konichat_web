# KoniChat - ChatBot
## Powered by Gemma2 model through Ollama

This Optimized for Konimex Project Purpose Only.

## Double Retriever
For RAG system, this project using `Double Retriever` combined between Ensemble Retriever (BM25 and Vector-base) and Vector-base, 
this drive to qulity of retrieval.

## Feature
- RBAC (Role Based Access Controll) for accessing spesific documents base on user's role.
- Admin for settings documents input
- Feedback loop mechanism base on user's feedback documents.
- Longer window context (8192) tokens.
- Token streaming
- Precision Answer
